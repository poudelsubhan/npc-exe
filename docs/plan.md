# Complete NPC.exe build
Done means a playable, visually polished journey with a manual workshop for rehearsal, a real Pine browser and downloaded artifact for live play, independent verification, audience-selected obstacles, recovery, and a concise demo guide.

1. Contract and verification: typed scene and blueprint; fixtures for valid, blocked, disconnected, stale, oversize and malformed artifacts. Gate: types and offline tests; commit.
2. Game and workshop: original courier/world art, challenge editing, palette, accessible drawing grid, export, import, crossing, receipt and retry. Gate: build, browser manual end-to-end, keyboard and small-screen check; commit.
3. Pine boundary: official SDK, view-only delegated desktop, scoped public workshop, bounded run, artifact retrieval and cleanup. Gate: adapter/offline lifecycle tests; one real live run if credentials supplied; commit.
4. Delivery: run scripts, tunnel helper, system design, demonstration script, source references, clean working tree. Gate: full local checks and honest live verification report; commit. No remote push without a configured destination.

Success measures: unverified imports never change the world; a changed rock configuration accepts an alternate route; every live run has a saved artifact hash; stopped/failed runs retain a usable next action; no live API calls in normal tests.
